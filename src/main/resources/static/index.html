Argos Configuration Editor

Build or edit a config.json without reading the docs. Everything happens in your browser: nothing is read from or written to the Argos server. Download the result, place it next to Argos and restart the service.

Monitors

What Argos checks. HTTP(S), TCP port, ping or DNS resolution.

E-mail channels (SMTP)

Alerts by mail. Each channel is one SMTP account with one or more recipients.

Webhook channels

Alerts as HTTP requests, e.g. to Slack, Mattermost, ntfy or a custom endpoint.

Status pages

Public or password-protected pages under /status/<id> showing the state of selected monitors.

General settings

Result

The file contains SMTP passwords and tokens in plain text: keep it out of version control and restrict it with chmod 600. Argos reads it from ./config.json or the path given as configPath=…; changes take effect after a restart.
